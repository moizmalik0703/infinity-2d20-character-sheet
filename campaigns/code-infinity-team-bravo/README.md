# Code Infinity — Team Bravo

Canonical archive for the Infinity 2D20 campaign **Code Infinity — Team Bravo**.

Campaign slug: `code-infinity-team-bravo`

## Archive structure

- `canon/` — current campaign state, timeline and unresolved threads.
- `sessions/` — one folder per played session. XML is the authoritative machine-readable session record.
- `assets/` — campaign-level logos, maps and shared artwork.
- Session-specific images and commendations should remain in the matching session folder.

## Canon rule

Played-session records supersede pre-session plans whenever they conflict.

The canonical record now extends through **Session 8 — Operation DAYBREAK**. All three Daybreak mission objectives were achieved. The current operational lead is the **manhunt for Pavel Rusk**, together with Bureau Toth's analysis of the preserved biological sample and the continuing investigation of PALE/07.
