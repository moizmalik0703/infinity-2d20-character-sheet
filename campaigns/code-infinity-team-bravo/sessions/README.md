# Session Archive

Each played session receives its own directory.

Recommended contents:

- `session-XX.xml` — authoritative machine-readable dossier log.
- `summary.md` — optional human-readable summary.
- `images/` — scene art used by campaign logs.
- `citations/` — commendations, reprimands or official correspondence tied to the session.

Played-session XML supersedes planning documents if the two conflict.
