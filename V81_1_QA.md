# V81.1 — Regression Suite & Quality Assurance

**Scope:** test and CI update only. The playable release remains `v81-approved-house-rules`. No changes to `index.html`, `app.js`, `data.js`, existing saved characters, or the campaign archive are intended.

## Independent baseline
`tests/fixtures/v81-baseline.json` is derived from the approved house-rule catalogue workbook (83 Traits and 69 Talents). It pins the name, effect, level and Infinity Point cost of every approved record independently of the runtime catalogue. The expanded runtime library has 318 Traits, 203 Talents, 521 records, including 12 playtest additions. The retained supplemental rules have not all been reconciled individually to sourcebooks.

| Check | V81 |
|---|---:|
| Legacy source-single / source-choice / special-effect Trait modes | 12 / 3 / 39 |
| Approved fixed Trait grants | 3 |
| Approved fixed Talent grants | 66 |
| Approved choice-based Talent grants | 3 |

Lucky's former special-effect mode was replaced by its approved mechanic. Charismatic gives a situational single-die reroll and no permanent Rating. Animal Handler gives an explicit +1 Animal Handling Rating and situational +1d20 when handling a companion; Command does not receive a permanent grant.

## Tests and deployment
1. Create a branch. Update the fixture only for explicitly approved rule changes; never derive expected values from the candidate app.
2. Open a pull request. Run Node regression, the V81 browser smoke and the entire Playwright suite against the checked-out application through a local HTTP server. Both local HTML and JS come from the same checkout.
3. Require all pre-deployment checks to pass before merging. The workflow itself does not enforce branch protection; configure required checks in repository settings if desired.
4. After merge, GitHub Pages publishes the app. The live workflow verifies the expected build marker and both JavaScript SHA-256 hashes against the checked-out release before running the full Playwright suite and V81 browser smoke against the public URL.
5. Inspect test logs and diagnostic artifacts if any check fails. Do not disable or weaken assertions merely to obtain a green result.

## Manual execution
Install Node 22, then:
```sh
npm install --no-save --no-package-lock @playwright/test@1.56.1
npx playwright install chromium
node tests/v81-house-rules.cjs
node tests/v81-browser-smoke.cjs
```
In one terminal serve the checkout with `python3 -m http.server 8765 --bind 127.0.0.1`; in another run `PORTFOLIO_URL=http://127.0.0.1:8765/ npx playwright test tests/e2e/ --reporter=line --workers=1`.
For the public URL use `node tests/wait-for-pages.cjs` followed by `npx playwright test tests/e2e/ --reporter=line --workers=1` and `SHEET_URL=https://moizmalik0703.github.io/infinity-2d20-character-sheet/ node tests/v81-browser-smoke.cjs`.

The browser suite covers manual and generated characters, faction/homeworld compatibility, skill/Focus allocation, abilities, XML save/load, print portfolio content, equipment and vehicle/TAG workshop, and mobile layouts. The tests do not certify gameplay balance, automatic dice adjudication, or physical print output; situational bonuses and Heat remain player-managed.
