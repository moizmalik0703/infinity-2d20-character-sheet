# Campaign Archive

This branch is reserved for campaign records and is intentionally separate from the live Infinity 2D20 character-sheet deployment on `main`.

## Safety rule

- `main` = live character-sheet application.
- `campaign-archive` = campaign records, session XML, canon notes and supporting assets.
- Do not merge this branch into `main` merely to publish or store campaign records.
- Changes in this branch are not required by the character-sheet application.
